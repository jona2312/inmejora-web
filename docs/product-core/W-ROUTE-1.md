The existing map looked up a case-sensitive pathname while React Router 6.30.6 matches case-insensitively and decodes route segments. `/PRESUPUESTO` could mount the historical quote form. Its writer did not independently check commercial mode.

The guard now uses the installed Router's `matchRoutes` with the existing destinations. No new routing authority or additional funnel is introduced. The legacy writer rejects `LEGACY_QUOTE_DISABLED` before inspecting form data, rate-limit storage or Supabase whenever sales mode is not explicitly false. Photo uploads remain disabled. `/contacto` and the private Project Core adapter are unchanged.
